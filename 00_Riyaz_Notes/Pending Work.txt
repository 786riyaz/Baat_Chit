- Use AI suggestions.

2. View previous messages.
3. Receive incoming messages.
4. Update profile.

ADMIN COMMUNICATION EXCEPTION:

A restricted pending user must always be allowed to open a personal chat with the configured admin user and send messages to the admin.

This allows the user to request approval or communicate with support.

The admin chat must remain visible and accessible.

For all other users, sending must be blocked after trial quota exhaustion.

When attempting to send a restricted message, display:

"Admin approval is required to continue messaging."

or similar professional UI text.
